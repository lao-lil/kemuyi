# C1 驾照 · 科目一（智能刷题 + 模拟考试 · PWA）

一个零依赖、可离线、可安装的科目一考试 PWA 网页。支持 **SM-2 间隔重复智能刷题**、**新题连续练习**、**仿真模拟考试**、**错题重练**四种模式，CDN 图片自动缓存本地，手机安装后可完全替代驾考 App 做日常练习。

## 🚀 在线使用

访问 **[https://lao-lil.github.io/kemuyi/](https://lao-lil.github.io/kemuyi/)**（GitHub Pages）

**安装到手机桌面**（推荐，体验等同原生 App）：
- **iOS Safari**：打开网址 → 分享 → 「添加到主屏幕」
- **Android Chrome**：打开网址 → 菜单 → 「添加到主屏幕」/「安装应用」
- **桌面 Chrome/Edge**：地址栏右侧安装图标 → 安装

安装后全屏启动、无浏览器地址栏，离线可用（首次需联网加载）。

## 四种模式

### 📚 刷题练习（智能精选）
基于 **SM-2 间隔重复算法**抽题，用最少时间巩固最多知识点：
- 优先复习**今日到期**的题目（错过的题间隔到期需要巩固）
- 引入适量**新题**（控制每日新题量，避免过载）
- 答题**即时判定**：答对变绿并自动进入下一题；答错停留当前题、标红所选并展示正确答案
- 立即展开**正确答案 / 解析 / 法条依据**
- 不限时，节奏完全可控

### 📝 模拟考试（仿真）
对标真实上机考试：
- 判断题 **40** + 单选题 **60**，章节分层抽样
- 限时 **45 分钟**，到点自动交卷
- 答题不揭示对错，交卷后统一评定
- 分数环 + 对错统计 + 逐题解析（错题置顶、可筛选）
- 答错的题自动注入 SM-2 复习队列

### 新题连续练习
只练所有模式中从未提交过答案的题：
- 排除刷题练习、新题连续练习、错题重练和模拟考试中已作答的题
- 使用全部剩余新题，不限制 100 题，不计时
- 自动保存题目顺序、当前位置、答案、判定和标记，关闭网页后可续练
- 答对后自动进入下一题，答错停留当前题查看解析
- 模拟考试中未选择答案的题仍会按错题评分，但不会被标记为“已作答”

### ❌ 错题重练
只练**错题本**中的题，与 SM-2 复习队列完全分离：
- 任何模式答错自动收录（含模考未答题，未答按答错处理，与真实考试一致）
- 任意模式答对一次即移出错题本
- 出题时 SM-2 今日到期的错题优先，答错重置间隔（明天再来）
- 全部攻克后首页错题数清零

## 🧠 SM-2 间隔重复算法原理

每题记录难度系数（ease）与复习间隔（interval）：

| 行为 | 算法响应 |
|------|---------|
| 答对 | interval 增长：1天 → 3天 → 7天 → 16天 → 35天…（按 ease 倍增），ease 微增 |
| 答错 | interval 重置为 1 天，ease 降低（最低 1.3） |

效果：**已掌握的题间隔越来越长、少打扰；薄弱的题频繁出现、强化记忆**。科学依据艾宾浩斯遗忘曲线，避免重复刷已会的题，专注薄弱点。

掌握判定：连续答对 ≥3 次且间隔 ≥7 天 → 标记为"已掌握"。

## 🖼️ 图片离线缓存

题目图片来自 CDN，采用 **Service Worker + Cache API** 实现本地缓存：

- **懒缓存**：看一题自动缓存一题，下次离线也能看
- **一键预下载**：首页点「📥 预下载图片库」可批量下载全部 714 张图片（约 50-100MB），完成后完全离线可用
- 预下载带进度条，可随时取消

## 📊 学习数据持久化

所有数据存储在浏览器本地（localStorage + Cache API），不上传任何服务器：
- SM-2 间隔记录（每题的 ease/interval/reps/due）
- 错题本（答错自动收录，答对一次即移出）
- 答题统计（累计正确率、模考历史、连续学习天数）
- 首页显示最近 3 次模拟考试成绩，可展开查看最多 50 次模考历史
- 全模式已作答题目与新题续练会话
- 图片缓存（Cache API）

首页可使用“导出记录”生成 JSON 备份，也可用“导入记录”合并另一台设备或另一网址来源的记录。导入兼容旧版 `kemuyi_sm2`、`kemuyi_wrong`、`kemuyi_stats` 备份，并会从 SM-2 和错题本推断旧题目历史；旧版模考历史只有总分，无法恢复其中每道答对题的题目 ID。

### Android Firefox 迁移

1. 在仍保存原网站历史的 Android Firefox 中导出旧站的 localStorage JSON。
2. 将本项目的新版本部署到 GitHub Pages，并在手机 Firefox 打开。
3. 首页点击“导入记录”，选择 JSON 文件并确认合并。
4. 导入成功后，新题剩余数、错题本、SM-2 进度和统计会立即刷新。

如果新版本仍部署在完全相同的域名和路径下，Firefox 会继续使用同一来源的 localStorage，通常无需导入；仍建议先导出备份。首页可「↺ 重置进度」清空学习记录重新开始。

## 本地开发与构建

```bash
python3 scripts/fetch_bank.py    # 下载/刷新原始题库（可选，data/ 已含）
python3 scripts/classify.py      # 规范化与分类（可选）
python3 scripts/build_html.py    # 生成 index.html / manifest.json / sw.js / 图标
```

依赖：Python 3.6+ + Pillow（生成图标用，`pip install Pillow`）。

**本地预览**：构建后双击 `index.html` 即可（功能正常，但 Service Worker 仅在 http/https 下生效）。
完整 PWA 体验需起本地服务：`python3 -m http.server` 后访问 `http://localhost:8000`。

- **原始数据**：开源项目 [`doupoa/DrivingTestSubjectOne`](https://github.com/doupoa/DrivingTestSubjectOne)，源自 **banban驾道**（最后更新 2022/07/17）
