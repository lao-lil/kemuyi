# 新题连续练习与学习记录迁移设计

## 目标

为现有科目一网页增加独立的“新题连续练习”模式，并解决用户从作者 GitHub Pages 网站迁移 Android Firefox 历史记录的问题。

新模式必须满足：

- 只展示所有模式中从未作答过的题目。
- 不限制单轮题数，持续练习直到全部未见题目完成。
- 不计时，界面明确显示“无计时”。
- 自动保存题目顺序、当前位置、答案和判定结果。
- 关闭页面或返回首页后，再次进入可继续上次进度。
- 答对后短暂停留并自动进入下一题。
- 答错后停留当前题，供用户阅读答案与解析。
- 支持导出、导入学习记录，并兼容当前旧版存储数据。

## 术语

- **已作答题目**：用户在刷题练习、新题连续练习、错题重练或模拟考试中提交过答案的题目。
- **未见题目**：不在统一已作答记录中的题目。
- **新题会话**：新题模式当前保存的题目顺序、位置及作答状态。
- **旧版记录**：现有应用使用的 `kemuyi_sm2`、`kemuyi_wrong`、`kemuyi_stats` 数据。

## 用户界面

### 首页入口

首页模式区域增加“新题连续练习”入口，展示：

- 剩余未见题目数量。
- 有未完成会话时显示“继续上次进度”。
- 所有题目都已作答时显示“新题已全部完成”，入口禁用。

首页模式说明由“三种模式”更新为“四种模式”，增加新题模式说明。

### 答题页

新题模式使用现有答题页和即时判定交互：

- 新增“新题”模式徽标。
- 计时区域显示“无计时”，不启动计时器。
- 题号显示为当前会话中的位置和总剩余新题数量。
- 答对后等待现有自动跳题延迟，再进入下一题。
- 答错后保持当前页面，用户手动进入下一题。
- 允许上一题、答题卡、标记和主动结束。

### 数据管理

首页增加“导出记录”和“导入记录”命令：

- 导出生成 UTF-8 JSON 文件。
- 导入通过文件选择器读取 JSON。
- 导入前展示确认提示，说明将合并还是覆盖数据。
- 本次实现采用**合并导入**：尽可能保留当前设备与备份中更完整的记录。
- 导入成功后刷新首页统计和新题剩余数量。
- 格式无效或内容损坏时不修改现有数据，并显示错误提示。

## 数据模型

### 统一已作答记录

新增 localStorage 键：

```text
kemuyi_seen
```

结构：

```json
{
  "question-id": 1770000000000
}
```

值为首次确认作答的时间戳。所有模式记录答案时都必须更新此集合：

- 刷题练习和错题重练：选择答案并即时判定时写入。
- 新题连续练习：选择答案并即时判定时写入。
- 模拟考试：交卷判分时，将所有已选择答案的题目写入。
- 模拟考试未答题不算“已作答”，即使考试评分将其按错题处理。

### 新题会话

新增 localStorage 键：

```text
kemuyi_new_session
```

结构：

```json
{
  "version": 1,
  "questionIds": ["id-1", "id-2"],
  "idx": 0,
  "answers": {"0": 1},
  "judged": {"0": true},
  "marks": {},
  "startedAt": 1770000000000,
  "updatedAt": 1770000000000
}
```

会话只保存题目 ID，不复制完整题目数据。恢复时通过当前题库重新映射，并剔除已经不存在的题目 ID。

保存时机：

- 创建新题会话后。
- 每次答题、跳题、标记或通过答题卡切题后。
- 返回首页或主动结束前。

会话清除时机：

- 当前会话中的题目全部完成。
- 用户执行“重置全部学习进度”。
- 恢复时发现会话无有效题目。

### 导出文件

导出格式：

```json
{
  "app": "driving-test-subject1",
  "version": 2,
  "exportedAt": "2026-07-30T00:00:00.000Z",
  "storage": {
    "kemuyi_sm2": {},
    "kemuyi_wrong": {},
    "kemuyi_stats": {},
    "kemuyi_seen": {},
    "kemuyi_new_session": null
  }
}
```

导入器兼容两种形式：

1. 新版导出的对象值。
2. Android Firefox 远程调试脚本导出的旧版字符串值。

## 新题选择与恢复

### 首次进入

1. 读取 `kemuyi_seen`。
2. 过滤题库，只保留不在已作答集合中的题目。
3. 随机排列全部未见题目，不截断为 100 题。
4. 创建并保存新题会话。
5. 从第一题开始。

### 继续练习

1. 读取已保存会话。
2. 校验版本和字段类型。
3. 过滤题库中已不存在的 ID。
4. 保留本会话中已经作答的题目。
5. 对本会话尚未作答的题目，再按最新 `kemuyi_seen` 过滤；被其他模式作答过的题目自动跳过。
6. 恢复题目顺序、位置、答案、判定和标记。
7. 如果当前位置越界，定位到最后一个有效位置。

过滤只删除被其他模式后来作答、且在本会话中尚未作答的题目；剩余题目的相对顺序保持不变。

## 旧版数据迁移

当前旧版没有统一的题目作答历史。导入旧版数据时：

- 完整恢复 SM-2 卡片、错题本和统计数据。
- 将 `kemuyi_sm2` 中存在的题目 ID 纳入 `kemuyi_seen`。
- 将 `kemuyi_wrong` 中存在的题目 ID 纳入 `kemuyi_seen`。
- 无法从旧版 `examHistory` 恢复模拟考试中每道答对题目的 ID，因为历史只保存总分和数量。
- 导入后所有新作答都会进入统一已作答记录，不再丢失题目级历史。

## 合并规则

- `kemuyi_seen`：取并集，时间戳取较早值。
- `kemuyi_wrong`：取并集；同一题累计错误次数取较大值，最近错误时间取较晚值。
- `kemuyi_sm2`：同一题选择 `last` 时间较新的卡片。
- `kemuyi_stats`：
  - 累计答题和答对数量取较大值，避免重复导入导致翻倍。
  - 学习日期取并集。
  - 模考历史按日期和成绩去重后合并，最多保留最近 50 条。
- `kemuyi_new_session`：当前设备已有有效会话时保留当前会话；否则采用导入会话。

## 现有模式调整

- `MODE` 增加 `NEW`。
- 自动跳题适用于 `PRACTICE` 和 `NEW`，不适用于 `WRONG` 或 `EXAM`。
- 新题模式答题仍调用现有 SM-2、错题本和统计记录逻辑。
- 模拟考试判分时补充记录已选择答案的题目 ID。
- 重置进度同时删除 `kemuyi_seen` 和 `kemuyi_new_session`。
- 普通刷题、错题重练和模拟考试的原有行为保持不变。

## 完成与主动结束

- 完成全部新题时进入练习总结，并清除新题会话。
- 主动点击“完成练习”时显示本次已完成题目总结，但保留会话，以便继续。
- 结果页“继续新题”返回保存位置。
- 当全部题库都已作答时，首页显示完成状态。

## 错误处理

- localStorage 读取失败时使用空记录，不阻止应用启动。
- localStorage 写入失败时继续当前会话，并提示“进度保存失败”。
- 导入 JSON 解析或结构校验失败时不写入任何键。
- 导入前先在内存中完成全部校验和合并，最后再统一写入。
- 题库升级造成会话题目缺失时自动剔除，无有效题目则清除会话。

## 测试

自动测试至少覆盖：

1. 新题列表排除刷题、错题、新题和模拟考试中已作答的题目。
2. 模拟考试未作答题不进入统一已作答记录。
3. 新题会话创建时包含全部未见题目，不受 100 题限制。
4. 页面重新初始化后恢复题目顺序、当前位置、答案和判定。
5. 新题答对自动下一题，答错保持当前题。
6. 主动结束保留会话，全部完成清除会话。
7. 旧版备份导入后恢复 SM-2、错题本和统计，并生成已作答集合。
8. 新版备份导入按合并规则工作。
9. 无效备份不会覆盖现有数据。
10. 重置功能清除新增存储键。
