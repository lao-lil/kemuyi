# 最近模拟考试成绩设计

## 目标

在科目一首页增加最近模拟考试成绩查看功能，让用户打开应用后可以快速看到近期表现，并能展开查看保存的完整模考历史。

## 范围

本次只增加成绩展示，不改变模拟考试的组卷、判分、错题注入或历史保存逻辑。

## 用户界面

首页统计区域下方增加“最近模拟考试”区域。

- 没有模考记录时显示“还没有模拟考试记录”。
- 有记录时按时间倒序显示最近 3 次。
- 每条记录显示：
  - 本地日期和时间
  - 分数
  - 合格或未合格状态
  - 用时
- 当历史记录超过 3 条时显示“查看全部”按钮。
- 点击“查看全部”后显示最多 50 条现有历史记录。
- 点击“收起”后恢复只显示最近 3 条。
- 区域为只读展示，不删除或修改记录，也不恢复旧的逐题解析页面。

## 数据与渲染

继续使用现有 `kemuyi_stats.examHistory` 数组，不新增 localStorage 键。

每条记录沿用现有字段：

```text
score   分数
right   答对数量
wrong   答错数量
time    用时（分钟）
date    时间戳
timeout 是否超时
```

新增 `renderExamHistory(expanded)`：

1. 读取并规范化 `loadStats().examHistory`。
2. 按 `date` 从新到旧排序。
3. 默认截取前 3 条，展开时显示全部可用记录。
4. 对缺失或非法字段使用安全默认值，不阻止首页渲染。
5. 根据 `score >= 90` 显示合格状态和对应颜色。
6. 使用本地时间格式化时间戳；无效日期显示“时间未知”。

首页初始化和返回首页时调用渲染函数。展开状态只存在于当前页面内，不写入 localStorage。

## 错误处理

- `examHistory` 不是数组时视为空历史。
- 单条记录不是对象时跳过。
- 分数、用时和数量缺失时使用 `0` 或 `—` 等安全展示值。
- 日期无效时显示“时间未知”。
- localStorage 读取失败时沿用现有 `loadStats()` 的默认统计行为。
- 渲染失败不影响刷题和模拟考试入口。

## 测试与验证

自动测试：

1. 记录按时间倒序展示。
2. 默认只显示最近 3 条。
3. 点击“查看全部”后显示全部可用历史。
4. 点击“收起”恢复 3 条。
5. 空历史显示空状态。
6. 异常记录不会导致渲染抛错。
7. 合格线使用 90 分。
8. 模板包含成绩区域和展开控制。

最终验证：

```text
node tests\exam_history.test.js
node tests\ui_markup.test.js
node --check src\app.js
python scripts\build_html.py
```
